# tonklasocute/homebrew-tap

Homebrew casks for [git-quill](https://github.com/tonklasocute/git-quill).

```sh
brew install --cask tonklasocute/tap/git-quill
```

`Casks/git-quill.rb` is regenerated from the latest git-quill release
(version and sha256 from its `checksums.txt`) by the
[Update cask](.github/workflows/update-cask.yml) workflow, which runs every
hour and can be started by hand. It needs no extra tokens.
